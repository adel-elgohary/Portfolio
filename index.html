Personal project

Server & Container Monitoring Stack

A ready-to-run monitoring stack that shows server and container health on live dashboards and sends alerts when something goes wrong.

CHALLENGE

Problems on servers and containers — a full disk, a crashed service, a CPU spike — usually go unnoticed until users complain.

MY ROLE

DevOps Engineer — designed the stack, wrote the alert rules, and built the dashboards.

ACTION

Packaged Prometheus, Grafana, Alertmanager, node_exporter, and cAdvisor in one Docker Compose file, defined alert rules for CPU, memory, disk, and container downtime, and built Grafana dashboards on top of the metrics.

RESULT

One docker compose up gives a live dashboard and alerts for the health of any Linux host and its containers — no manual setup.
